# 模型复杂度
简单模型在新数据上的泛化能力优于复杂模型。也就是说，简单模型在测试集上的预测效果比复杂模型更好。

长期以来，简单性一直胜过复杂性。事实上，对简单性的偏好可以追溯到古希腊。几个世纪后，一位十四世纪的修士奥卡姆的威廉将这种对简单性的偏好正式化为一种哲学，即奥卡姆剃刀原理。这一哲学至今仍是包括机器学习在内的许多科学领域的基本指导原则。

> 复杂模型通常在训练集上优于简单模型。然而，简单模型通常在测试集上优于复杂模型（这一点更为重要）。

>最好让您的数据收集流程从仅一两个特征开始。这将帮助您确认机器学习模型按预期工作。此外，当您基于几个特征构建基线时，您会感觉自己正在取得进展！

保持模型简单的一种方法是惩罚复杂模型；也就是说，在训练过程中迫使模型变得更简单。惩罚复杂模型是正则化的一种形式。

当目前为止， 训练时的唯一目标是最小化损失， 只专注于最小化损失的模型往往会过拟合。更好的训练优化算法会最小化损失与复杂度的某种组合。

不幸的是，损失与复杂度通常呈反比关系。随着复杂度增加，损失会降低。随着复杂度降低，损失会增加。你应该找到一个合理的中间地带，使模型在训练数据和现实世界数据上都能做出良好预测。也就是说，你的模型应该在损失与复杂度之间找到合理的折中。
