我们知道，神经网络使用嵌入向量来表示词汇。但这些嵌入从何而来? 有一些专门的神经网络架构致力于解决这个问题。
接下来，让我们一起了解一下 Word2Vec 神经网络,它将学习如何将词语表示为高纬向量。

请记住， 有很多方法可以做到这一点。
所以这只是一个例子。
向任何优秀的神经网络一样， 我们从输入层开始。我们可以在这里使用独热编码。因此， 我们需要为词汇表中的每个单词设置一个输入节点。

我们将这一层与下一层进行全连接，下一层的每个神经元对应目标嵌入空间中的一个维度。

例如， 如果我们想要10维嵌入， 下一层将有10个节点。

这一层通常被称为 “投影层” 或 "嵌入层"。

我们将在这里学习嵌入。请注意，这一层不需要使用激活函数。在嵌入层之后，我们可以使用带有激活函数的全连接隐藏层，对数据进行进一步处理。

最后，我们的输出层将与我们的输入层具有相同的结构，词汇表中的每个词都对应一个神经元。

这将使用 softmax 函数来归一化我们的输出。 现在我们有了神经网络，该如何训练它呢？

给定一个词， 我们将会长似乎预测哪些词会出现在相同的上下文中。

我们将处理大量文本， 比如古腾堡计划中的每一部英文小说或英文维基百科上的所有文章， 将其转换为输入-输出对。

输入将是文本中的一个词， 而输出， 即我们试图预测的值， 将是同一句子中附近的一个词。

这些输入-输出对被称为 Skip-grams（跳元词对）， 我们生成的 Skip-grams 越多，我们的模型效果就越好。但训练所需的时间也会越长。

训练完成后， 网络第一层与第二层之间的权重就是我们的 **嵌入矩阵**。

也就是说， 要找到某个词的嵌入， 只需将该词的所有权重堆叠成一个向量。得到的向量维度会更低。生成的向量维度会更少， 

比我们的独热编码表示更好，并且能够编码有关词汇含义的信息。

这样做的一个结果是，相似的词汇在向量空间中往往彼此更加接近。

例如，帆（sail）和船（ship）的嵌入向量很可能彼此接近，而“如何”（how）的嵌入向量则很可能与它们相距较远。

请注意，这个简单的神经网络并未针对性能（Performance）进行优化，训练它需要大量的时间和内存（Memory）。

# Contextual Embeddings（上下文嵌入）

word2vec 静态嵌入向量的一个局限是，词语在不同的上下文中可能具有不同的含义。“Yeah”单独出现时是一种意思，但在短语“Yeah, right.”中则表达相反的意思。
“Post”可以表示“邮件”、“投递邮件”、“耳环背扣”、“赛马终点标志”、“后期制作”、“柱子”、“张贴通知”、“派驻警卫或士兵”或“之后”，以及其他可能的含义。

然而，在静态嵌入中，每个词在向量空间中都只由一个点表示，即使这个词可能具有多种含义。

在上一个练习中，你发现了静态嵌入在处理单词 orange 时的局限性：它既可以表示一种颜色（橙色），也可以表示一种水果（橙子）。

由于只有一个静态嵌入向量，在使用 word2vec 数据集训练时，orange 总是会比 juice（果汁）更接近其他颜色词。

上下文嵌入（Contextual Embeddings） 正是为了解决这一局限性而开发的。上下文嵌入允许同一个词拥有多个不同的嵌入表示，
这些嵌入不仅包含词本身的信息，还会结合其周围词语的信息。

对于数据集中每一个包含 orange 的不同句子，orange 都会获得一个不同的嵌入表示。

一些创建上下文嵌入的方法，例如 ELMo，会先获取一个词的静态嵌入，例如句子中某个词对应的 word2vec 向量，
然后通过一个能够结合该词周围词语信息的函数对其进行转换，从而生成上下文嵌入。

虽然上面介绍的模型都是语言模型，但上下文嵌入在其他生成任务中也很有用，例如图像生成。

以一张马的照片为例，如果将像素 RGB 值的嵌入，与表示每个像素位置的位置矩阵，以及对相邻像素进行的某种编码结合起来，就能生成上下文嵌入，
为模型提供比单独使用原始 RGB 值的静态嵌入更多的信息。
