# 数据集-转换数据
机器学习模型只能基于浮点值进行训练。然而，许多数据集特征并非天然就是浮点值。因此，机器学习的一个重要部分就是**将非浮点特征转换为浮点表示**。

例如，假设 `street names` 是一个特征。大多数街道名称都是字符串，例如“Broadway”或“Vilakazi”。您的模型无法基于“Broadway”进行训练，因此您必须将“Broadway”转换为浮点数。

此外，即使特征本身已经是浮点数，通常也需要进行适当的转换。这一过程称为[归一化 （Normalization）](../%E6%95%B0%E6%8D%AE%E5%A4%84%E7%90%86-%E5%BD%92%E4%B8%80%E5%8C%96/README.md)，它将浮点数缩放到一定的数值范围内，从而提高模型的训练效率。

## 当数据过多时进行采样
一些组织拥有海量数据。当数据集包含过多样本时，需要从中选择一部分样本用于模型训练。如果条件允许，应尽量选择与模型预测任务最相关的样本。
>你要预测芝加哥市区的出租车车费，那么可以优先考虑市区的行程数据，而不是大量其他地区的行程数据。


个人身份信息（PII）：训练数据应尽量避免包含可识别个人身份的信息。可以通过删除相关字段、去标识化等方式保护隐私，同时尽量保留有效样本。
