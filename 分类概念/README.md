分类是预测一个示例属于一组类别（分类）中哪一个的任务。

多类别分类（Multi-class Classification）可以看作是二分类（Binary Classification）向两个以上类别的扩展。

然后，对每个原始类别重复这个过程。

多类别分类的一个例子是手写数字识别器。它接收一张手写数字的图像，并判断图像中表示的是哪个数字（0～9）。

如果类别归属不是互斥的，也就是说，一个样本可以同时被分配到多个类别，那么这就称为多标签分类（Multi-label Classification）问题。
