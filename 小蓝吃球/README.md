# 小蓝吃球

个人机器学习学习与练习项目，使用 AI 辅助开发。

## 教程来源与章节对应

参考 [B 站教程第一节：一元一次函数感知器：如何描述直觉](https://www.bilibili.com/cheese/play/ep6174)。

代码参考教程编写，并会根据个人理解做少量修改，不保证与教程逐行一致。

| Python 文件 | 对应章节 | 当前内容 |
| --- | --- | --- |
| `lr_manual.py` | 第一节《一元一次函数感知器：如何描述直觉》 | 用 `y = wx` 预测豆子毒性，逐样本通过梯度下降更新权重，并绘制数据与拟合直线。 |
| `dataset.py` | 第一节练习使用的数据生成辅助文件 | 生成豆子大小与带随机噪声的毒性数据。 |
| `perceptron_manual.py` | 暂未对应具体章节 | 仅包含模块说明，尚未实现算法。 |

教程将其称为“罗森布拉特感知器”，但当前 `lr_manual.py` 实现的是不带偏置的一元线性回归模型：直接使用 `y = wx` 预测连续数值，没有经典罗森布拉特感知器的阈值分类步骤。

代码手动实现了按固定顺序逐样本进行的梯度下降，没有随机抽样或打乱样本顺序。每次使用一个样本，通过 `w = w + alpha * (y - y_pre) * x` 更新权重，其中 `alpha` 是学习率。

该更新公式来自单个样本的平方误差损失 `L = 0.5 * (y - y_pre) ** 2` 对权重的求导。代码计算了误差 `e = y - y_pre`，直接使用推导好的梯度更新权重，没有显式计算或记录 loss 的数值。这是实际的梯度下降训练过程；线性回归也可以使用学习率迭代求解参数。

外层 `for _ in range(100)` 表示训练 100 个 epoch（轮次），每轮完整遍历全部 100 个样本。内层 `for i in range(100)` 用于逐个取出样本，不表示批次大小。由于每个样本都会触发一次权重更新，批次大小相当于 1，总共更新权重 10000 次；这与每次使用全部样本的平均梯度、每轮只更新一次权重的全批量梯度下降不同。
