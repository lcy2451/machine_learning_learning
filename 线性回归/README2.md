线性回归是一种用于查找变量之间关系的统计技术。在机器学习背景下，线性回归用于查找特征与标签之间的关系。

###### 从散点图可以看出，行驶里程越远，车费总体上越高，两者呈现明显的正相关关系。虽然部分数据点偏离了整体趋势，这里仍仅使用行驶里程作为输入特征，学习它与车费之间的线性关系。

我们可以通过绘制一条穿过这些点的最佳拟合线来创建我们自己的模型：

用代数术语来说，该模型可以定义为$y = mx + b$，其中
- $y$是每加仑行驶的英里数——这是我们想要预测的值。
- $m$是直线的斜率。
- $x$代表英镑——我们的输入值。
- $b$是 y 轴截距。

在机器学习中，线性回归模型的方程可以写成如下形式：
$$
y = b + w_1x_1
$$
$y$ 是预测标签——即输出。
$b$是偏差 模型偏差的概念与代数方程中的 y 轴截距相同。 直线方程。在机器学习中，偏差有时被称为 $w_0$。偏差是模型的一个参数 ，在训练过程中计算。

$w_1$是特征的权重 。权重与代数方程中的斜率 $m$ 概念相同。 直线方程。权重是 该模型的参数是在训练过程中计算的。
$x_1$ 是一个特征 ——输入。
在训练过程中，模型会计算出能够产生最佳模型的权重和偏差。


### Loss 损失
Loss 是一个数值指标，用于描述模型预测的误差程度。 损失衡量模型预测值与实际值之间的距离。 标签。训练模型的目标是最小化损失，使其减少到其预期值。 最低值。
##### 在线性回归中，损失主要分为五种类型

| 损失类型 | 定义  | 代码  |
| ---- | --- | --- |
|   L1 loss   |  预测值与实际值之差的绝对值之和。   |     |
|   平均绝对误差（MAE）   |   在 N 个样本中 L 1 损失的平均值。  |     |
|   L2 loss  |   预测值与实际值之差的平方和。  |     |
|   均方误差（MSE）   |   在 N 个样本中 L 2 损失的平均值。  |     |
|   均方根误差（RMSE）   |  均方误差（MSE）的平方根。   |     |

### 梯度下降法
梯度下降是一种数学方法，它通过迭代寻找使模型损失最小的权重和偏差。
梯度下降是一个迭代过程，它找到使模型损失最小的权重和偏差。

该模型首先使用接近于零的随机权重和偏差进行训练，然后重复以下步骤：
- 使用当前权重和偏差计算损失。
- 确定调整权重和偏差的方向，以减少损失。
- 将权重和偏差值向减少损失的方向进行小幅调整。
- 返回第一步，重复该过程，直到模型无法进一步减少损失为止。


### 超参数
超参数是控制训练各个方面的变量。三个常见的超参数是：
Learning rate  学习率
Batch size  批量大小
Epochs  纪元

随机梯度下降法 (SGD) ：随机梯度下降法每次迭代仅使用一个样本（批次大小为 1）。迭代次数足够多时，SGD 可以有效工作，但噪声非常大。“噪声”指的是训练过程中出现的波动，这些波动会导致损失值在每次迭代中增加而不是减少。“随机”一词表明每个批次中的样本是随机选择的。
还有小批量梯度下降（Mini-batch GD）
批量梯度下降（BGD）
