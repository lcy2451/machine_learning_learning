> 我们本着“如无必要，勿增新知”的理念，按当前需要决定学习深度，不必把每个细节都研究透。先让代码跑起来，理解基本过程，确认结果合理，再继续往前走；遇到问题或真正需要时，再深入学习，避免陷在细节里停滞不前。
## 内容入口

- [卷积](./卷积/README.md)：与“小蓝吃球”同一教程的后续章节，当前已建立独立目录及来源说明，尚无卷积实现。
- [线性回归练习](./线性回归/README.md)：PyTorch 训练、绘图及 ONNX 导出与预测。
