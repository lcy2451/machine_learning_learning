个人机器学习学习仓库，用于整理学习笔记、算法实现和练习代码。

> 我们本着“如无必要，勿增新知”的理念，按当前需要决定学习深度，不必把每个细节都研究透。先让代码跑起来，理解基本过程，确认结果合理，再继续往前走；遇到问题或真正需要时，再深入学习，避免陷在细节里停滞不前。

## 内容入口
1. [线性回归练习](./线性回归/README.md)：PyTorch 训练、绘图及 ONNX 导出与预测。
2. [损失函数loss](./损失函数loss/README.md)：损失函数基础笔记。
3. [优化器](./优化器/README.md)：优化器基础笔记与现有 SGD 训练示例入口。
4. [数据处理-归一化](./数据处理-归一化/README.md)：线性缩放、Z 分数缩放与对数缩放的学习笔记和 Python 练习。
5. [数据处理-分箱](./数据处理-分箱/README.md)：分箱（分桶）的基本概念，将连续数值按区间划分为类别。
6. [数据处理-清洗](./数据处理-清洗/README.md)：数据清洗的基本概念，处理缺失值、重复记录和错误数据。
7. [数据处理-多项式变换](./数据处理-多项式变换/README.md)：多项式特征的基本概念，通过幂次项和交互项扩展输入特征。
8. [类别数据处理-独热编码](./类别数据处理-独热编码/README.md)：独热编码的基本概念，以及使用 pandas 将类别转换为数值的示例。
9. [小蓝吃球](./小蓝吃球/README.md)：线性回归的拓展实践，包含手写梯度下降、解析公式求解及 PyTorch 实现。
10. [公平性练习](./公平性/README.md)：TensorFlow / MinDiff、PyTorch 收入分类、ONNX 分组评估、样本加权与 MMD 实验。
11. [卷积](./卷积/README.md)：卷积神经网络相关实践。
