# 数据集-标签

**直接标签**（Direct labels）：指与模型想要预测的结果完全一致的标签。也就是说，模型要预测的结果已经作为一列存在于数据集中。例如，对于一个用于预测某人是否拥有自行车的二分类模型，数据集中名为 bicycle owner（自行车拥有者）的列就是一个直接标签。

**代理标签（Proxy labels）**：指与模型想要预测的结果相似，但并不完全一致的标签。例如，订阅《Bicycle Bizarre》杂志的人很可能拥有一辆自行车，但并不一定如此。

直接标签通常比代理标签更好。 如果数据集中存在可以使用的直接标签，那么通常应该优先使用它。不过，很多时候我们无法获得直接标签。

代理标签始终是一种折中方案，是对直接标签的不完全准确的近似。然而，有些代理标签与直接标签足够接近，因此仍然具有实用价值。使用代理标签的模型，其实用性取决于代理标签与模型所要预测的结果之间的关联程度。

请记住，与**特征向量（Feature Vector）**类似，每个标签都必须表示为浮点数（因为机器学习本质上就是一系列数学运算）。

有时，虽然存在直接标签，但很难将其表示为浮点数。在这种情况下，可以使用代理标签。
